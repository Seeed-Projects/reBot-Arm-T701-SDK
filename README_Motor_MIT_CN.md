# T701-HT 单电机 MIT 控制

[English](README_Motor_MIT.md)

## 1. 实机准备

按 [T701-HT SDK 中文说明](README_CN.md) 安装环境并配置串口映射。左臂接 CAN1，右臂接 CAN2。

每次打开新终端，先激活已安装的环境，并在项目根目录执行后续命令：

```bash
conda activate t701-ht
```

### 安全提示

> **执行示例命令后，所选电机会立即开始运动，无需再次确认。运行前固定好设备，确认电机零点并清空整个运动范围；全程现场看护，手和身体远离电机、关节及夹爪夹点。**

原例程目标幅值为 **±π rad（±180°）**，不使用 URDF 高层限位，也不叠加重力补偿。运行前确认所选电机及其连接机构允许该轨迹。首次按 `Ctrl+C` 会触发回零，需同时预留回零空间；回零期间再次按下可中断回零并尝试发送刹车。

## 2. 运行示例

从项目根目录运行，只控制指定 CAN 通道上的一个电机。默认示例选择左臂 CAN1 的 8 号电机。

| 示例 | 运行命令 | 预期行为 |
| --- | --- | --- |
| 左臂 CAN1、电机 ID8（默认示例） | `python scripts/motor_example/t701_ht_pos_vel_torque_kp_kd_control.py --can-port 1 --motor-id 8 --arm left` | 单电机执行 MIT 五参数正弦跟踪，周期性打印位置、速度、力矩、模式及故障码。 |
| 右臂 CAN2、电机 ID8 | `python scripts/motor_example/t701_ht_pos_vel_torque_kp_kd_control.py --can-port 2 --motor-id 8 --arm right` | 相同轨迹，使用右臂的电机型号及回零配置。 |

三个参数均必填：`--can-port` 为逻辑 CAN 通道（1–7），`--motor-id` 为电机 ID（1–8），`--arm` 为 `left` 或 `right`。`--arm` 只选择配置，不自动选择 CAN 通道，也不对右臂轨迹取反。

## 3. MIT 参数与退出

```python
motor.pos_vel_tqe_kp_kd(pos, vel, 0.0, 2, 0.5)
robot.motor_send_cmd()
```

| 参数 | 原例程设定 |
| --- | --- |
| 目标位置 `pos` | `π × sin(2π × 0.1 × t)` rad，频率 0.1 Hz、周期 10 秒。 |
| 目标速度 `vel` | 位置目标的时间导数，峰值约 1.974 rad/s。 |
| 前馈力矩 `torque` | 0 Nm。 |
| `Kp` / `Kd` | 2 / 0.5。 |
| 循环等待 | 每次发送后等待 0.001 秒，实际周期还包含通信和打印耗时。 |

`t` 沿用原例程的 `time.time()`，起始相位随启动时间变化。源码注释中的“幅值 1.0 rad”与公式不一致，此次搬运保留原代码及参数。

按 `Ctrl+C` 后，所选电机先平滑回到零位，再发送阻尼刹车。回零使用位置、速度、最大力矩接口；回零期间再次中断，或反馈无效时，收尾逻辑尝试发送刹车。请为回零路径留出空间。
